# 證明排序評分 ProofScorer

完整的使用方法、計分範例與極端情況說明請見 **[使用說明](docs/使用說明.md)**。

## 使用方式
- 線上版：https://n753951f.github.io/proof-scorer/ （直接用瀏覽器開啟，不需下載）
- 下載：[Releases](https://github.com/n753951f/proof-scorer/releases)
  - `ProofScorer-x.x.x-portable.exe`：免安裝執行檔（Windows x64），雙擊即可使用
  - `ProofScorer.html`：單檔網頁版，功能相同，雙擊用瀏覽器開啟（電腦開啟「智慧型應用程式控制」擋下 exe 時使用）

## 計分規則
1. X 定位：正解為 X 的 ID，學生也判為 X（未使用）→ 每個 1 分
2. 學生答案轉成「步驟→ID」序列
3. 沿學生序列走，找出在正解中也連續相接的最長片段，長度即序列分
4. 總分 = X 分 + 序列分（滿分 = ID 總數）

## 格式
- ID→步驟：`2→X→6→1→3→X→4→7→X→5`（第 n 個值 = ID n 的步驟，不用的寫 X）
- 步驟→ID：`4→1→5→7→A→3→8→X→X→X`（依步驟寫出使用的 ID；結尾的 X 可省略，寫成 `4→1→5→7→A→3→8` 也算對）
  - 學生答案的 X 若寫在中間（如 `4→1→5→X→7→A→3→8`），會中斷正確序列的計算
  - ID→步驟 的 X 只用來定位，先定位 X 再轉成步驟→ID，不會中斷序列
- 分隔符可用 `→ -> , 、 空白`，或完全不加（`2X613X47X5`）；10 以上的 ID 用 A、B、C…
- 學生答案自動判斷格式（長度不等於 ID 數、或出現大於使用項數的編號（如只用 7 項卻有 A）→ 步驟→ID；X 夾在中間 → ID→步驟；其餘同正確答案格式），每筆的格式標籤可點擊切換

## 操作
- 任何地方按 Enter：新增一筆 → 輸入學號 Enter → 輸入答案 Enter
- 學號不填直接 Enter：自動產生隨機學號
- 從 Excel 複製「學號、答案」兩欄直接貼到輸入框：一次加入多筆
- 雙擊某筆：編輯；滑鼠移到列上按 ×（或選取後按 Delete）：刪除
- ↑ ↓：切換查看的學生；Ctrl+F：搜尋學號
- 系統不儲存任何資料，請用匯出 CSV 保存

## 開發
```
npm install
npm start          # 開發執行
npm test           # 計分邏輯測試
npm run html       # 產生單檔網頁版
npm run dist       # 打包 exe（專案路徑需短於約 100 字元，NSIS 有路徑長度限制）
```
